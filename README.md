# Breast Cancer Prediction Application

A machine learning web application designed to predict breast cancer outcomes based on relevant input features.

This project covers the machine learning workflow, including data preparation, model development, training, and integrating the trained model into a web-based application.

## Features

- Predict breast cancer outcomes based on user input
- Machine learning model for classification
- Web-based user interface
- Model development and training notebook included
- Flask-based application

## Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- Machine Learning
- HTML
- CSS

## Project Structure

```text
├── model/                    # Saved machine learning model
├── templates/                # HTML templates
├── app.py                    # Flask application
├── model_building.ipynb      # Model development and training
├── requirements.txt          # Project dependencies
```

## How to Run Locally

1. Clone the repository

```bash
git clone https://github.com/Tife-p/BreastCancer_Project_POPOOLA_BOLUWATIFE_22CD032199.git
```

2. Navigate into the project folder

```bash
cd BreastCancer_Project_POPOOLA_BOLUWATIFE_22CD032199
```

3. Install the required dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python app.py
```

5. Open the local address displayed in your terminal in your browser.
